Backend интеграция (cookie-auth)

При логине backend выдаёт cookie:

res.cookie('token', jwt, {
  httpOnly: true,
  secure: true,
  sameSite: 'strict',
  maxAge: 7 * 24 * 60 * 60 * 1000,
});
res.send({ success: true, user });


Frontend-запрос:

await fetch(`${API_BASE}/auth/login`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email, password }),
  credentials: 'include',
});


Для последующих API-вызовов также:

fetch(`${API_BASE}/api/v1/deals`, { credentials: 'include' });
